# Balrum - German Translation / Deutsche Übersetzung
1. Den Ordner "de" für deutsche Übersetzung im Spieleordner Balrum\files\dialogs\ überschreiben oder die Dateien im Ordner "de" in den Spieleordner Balrum\files\dialogs\de\ kopieren.
2. Spiel starten und unten rechts auf die Sprache "German" stellen.
3. Spiel beenden und neu starten, dann sollte das Spiel auf Deutsch sein.
